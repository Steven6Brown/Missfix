# Missfix — Brand Guide

**Working tagline (proposed):** Find your miss. Fix it.

## The mark
A target with an orange miss off to one side and a lime arrow pulling it back to the bullseye: the miss, found and fixed.

## Files
| File | Use |
|---|---|
| `missfix-app-icon.svg` / `.png` | App Store / home screen icon. 1024×1024, opaque, square (the system applies the rounded mask). |
| `missfix-mark-on-light.svg` / `.png` | Transparent mark for light backgrounds. |
| `missfix-mark-on-dark.svg` / `.png` | Transparent mark for dark backgrounds. |
| `missfix-wordmark-on-light.svg` / `.png` | Mark + name + tagline for light backgrounds. |
| `missfix-wordmark-on-dark.svg` / `.png` | Mark + name + tagline for dark backgrounds. |

## Palette
| Name | Hex | Use |
|---|---|---|
| Night | `#111827` | Icon field, text, dark surfaces |
| White | `#FFFFFF` | Target rings, light surfaces |
| Fix Lime | `#C6F432` | Bullseye, correction arrow, key actions |
| Miss Orange | `#FF6B35` | The miss, warnings |

## Type
Headings and numbers: SF Pro Rounded (bold). Body: SF Pro (system). The wordmark SVGs reference these fonts by name, so **convert the text to outlines in a vector editor before using a wordmark in print or on the web**, otherwise it will fall back to another font on machines without them.

## Voice
Coach-like, specific and encouraging. Name the pattern in plain words ("your 7-iron misses right"), give one thing to work on, never a lecture.

## Name check
On 2026-10-14 a search of the US App Store found no app titled exactly "Missfix". This is not a trademark search and not a guarantee the name will be accepted: check App Store Connect name availability and run a USPTO search before committing. Alternates considered: Rangeloop, Missmap.

## Icon rules
- Keep the mark inside the central ~80% of the icon canvas.
- No text on the icon.
- Check the icon at 60×60 pt and in dark, tinted and clear iOS appearances before submission.
